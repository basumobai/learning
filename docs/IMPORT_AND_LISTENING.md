# 账号、服务器 PDF、OCR 与广东听说

## 账号入口

用户从登录页“创建自己的账户”进入 `/register`，填写用户名、显示名称与15–128字符密码。新账户固定为learner，由服务器分配默认身份组，不能自行指定管理员角色或模型权限。

管理员在 `/admin#users` 的“自主注册”开关注册、设置新用户默认身份组，仅影响此后注册用户。原账号和分组不变。注册有安全限流和密码计算并发保护；代理后的多个用户可能共享注册安全限流，不限制学习/AI调用次数。

自己的密码：顶部姓名或“设置 → 密码与登录安全”(`/settings#security`)。重置他人密码：管理 → 账户 → 选择用户 → 填写重置密码，该用户首次登录后必须改密。改密撤销旧会话。当前没有邮箱找回，忘记密码联系管理员。

## 把 PDF 放在哪里

默认宿主机目录是仓库下的 `data/pdf/`，本次部署对应 `/www/wwwroot/learning/learning/data/pdf/`。

在仓库根目录执行 `install -d -m 755 data/pdf` 创建目录。放入例如 `选择性必修一-题目.pdf` 和 `选择性必修一-答案.pdf`；文件需允许容器用户读取，目录需有遍历权限。不要放到数据库卷或容器临时目录。

自定义目录时在 `.env` 添加 `LEARNING_PDF_DIR=/你的/PDF目录`，重建API。Compose只读挂载到 `/data/pdf`，页面显示当前挂载来源。只列目录第一层PDF，最多500项；每份最大32MB、200页。子目录、越界路径和外部符号链接不能导入。

进入管理 → 多学科管理 → 资料入库 → 从服务器目录导入PDF，刷新目录、选择题目与答案。默认自动识别学科、版本和册次；选择资料后核对依据并确认，才开始章节识别。手动提供科目只是线索，仍需确认。两者在同一PDF时可选择同一文件，再按物理页分别指定范围。网页上传、WebDAV继续保留。详见[教材归档与高考题型](CURRICULUM.md)。

导入保存PDF快照，后台自动开始文本提取、扫描页OCR与教材归类；确认后识别目录。修改源文件不会自动改动已入库题目。相同文件和元数据重复导入复用已有记录。不会无人审核直接发布。

## AI任务分工

在多学科管理 → AI提示词与模型分别配置：

| 任务 | 输入与输出 | 模型要求 |
| --- | --- | --- |
| 扫描页OCR | 单页图 → 逐字文本、不确定位置，禁止解题 | 视觉模型 |
| 学科与教材归类 | 各页文字线索 → 学科、实际版本/册次、原文依据和不确定说明 | 文本模型 |
| 目录识别 | 原生/OCR文本和必要页图 → 章节与题目/答案页 | 建议视觉模型 |
| 题干与选项提取 | 仅题目页 → 材料、题干、小题、选项、插图位置 | 视觉模型 |
| 参考答案提取 | 仅答案页 → 答案、原始依据、解析与评分标准 | 视觉模型 |
| 题目答案配对 | 两份结构 → 一对一编号对应，禁止改写 | 文本模型 |
| 广东听说A/B/C | 题型+主题+重点 → 原创专项练习 | 学生选的授权聊天模型 |
| 听说作答文本评价 | 已交卷手动转写+参考 → 逐项反馈和修改 | 学生选的授权聊天模型 |
| 动态讲解/题内追问/评分 | 当前题与实际作答 → 对应讲解 | 按任务配置 |

PDF相关任务也可用已有独立Codex入库服务，保留原权限边界。新任务首次创建时继承旧目录/提取任务的模型与后端，默认提示词独立保存，既有自定义提示词不覆盖。旧“题目与答案入库”配置保留作升级参考。

选中资料，展开“OCR识别与逐页核对”，查看原生/待识别/OCR状态、文字、不确定说明和原图。仅处理待识别页，已完成页进度保留；修复配置后可单独补跑，再重试目录任务。

目录完成后选择小节，核对物理页码（从1开始，每侧最多8页）并提交提取。题干与答案由不同任务读取，配对模型仅选已有编号。配对不完整、答案依据缺失或页码越界即失败。成功后仍是草稿，核对原PDF后发布。

## 广东英语听说专项

AI助学 → 听力训练 (`/assistant#listening`)：

| 类型 | 训练流程 |
| --- | --- |
| Part A模仿朗读 | 约一分钟原创材料，听音看稿、准备计时、录音回放、核对意群停顿建议 |
| Part B角色扮演 | 直接听录音 → 3个中文提示问句 → 每次提问后听计算机回答记笔记 → 听5个英文问题并回答 |
| Part C故事复述 | 故事建议听两遍 → 关键词和笔记 → 一分钟准备 → 录制复述 → 交卷核对信息点 |
| 基础听力四选一 | 保留选择题与交卷后原文依据，作为基础专项 |

除主题、难度外可选数字地点变化、问句结构、笔记信息保持、故事主线、意群连读等重点。计时由用户启动，可按步骤反复练；这是题型专项，不是强制倒计时的正式全卷模拟。

交卷前不返回B/C原文、参考表达或答案；A的朗读稿是题型必要材料。B的问题与计算机回答独立语音播放。训练、作答、语音缓存和AI反馈均按账户隔离。

录音通过浏览器MediaRecorder本机处理，仅当前页面保留，离开前可下载。目前**不上传录音、不自动转写、不做专业语音评分**。填写自己的英文作答/手动转写，交卷后可请求AI逐项评价内容、问句与表达，不给“官方听说分”。模型和TTS质量取决于接入服务商。
