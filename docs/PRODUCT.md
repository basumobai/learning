# 产品行为

当前面向高中英语词汇练习，词库只有五个原创示例词；没有正式北师大版教材词库、账户或 AI。词义与识别、释义回忆、拼写三种能力分别存储。

## 队列

默认按计划学习，可选题型、最多题数与本轮新能力项上限。优先取已到期能力，按到期时间排序并随机选择同词义的题型，新能力项随机抽取。每轮只出现每个词义的一种题型；北京时间当日已正式复习的词义，其其它题型延至次日，避免答案互相提示。同一题型的短期学习步到期后可继续当天复习。到期计数包含所有能力项，部分同词义能力会因避让暂时不出题。

自由练习允许提前随机抽题，一轮仍避开同词义的多题型重复。记录答题与评级，不改正式复习状态，不触发当天同词义避让。本轮上限不是每日预算。当前每次读取最多 3000 个候选能力项，正式词库阶段须继续优化大型队列查询。

## 回忆、核对、评价

提交后停留在原题，展示原答案、参考答案和例句。参考答案不会在提交前通过 Session 接口返回。选择题随机选项；拼写仅忽略首尾空白和字母大小写，不删内部空格或标点。自由释义匹配主释义或别名判对，未匹配且非空为 pending；学生对照参考答案选择自评正确/错误，保留 initial_result 与 resolved_result，不把自评冒充 AI 判分。

在反馈页选择 1 重学、2 困难、3 记住了、4 很轻松。答错或使用提示只能重学；未完成核对的 pending 不可评级。空输入只能由 API 提交，判错。服务端禁止跳过当前题或改写已确认评价。

FSRS-6 使用 go-fsrs/v4 v4.0.0，默认 90% 目标保持率、默认学习/重学步；保存完整 card 和 ReviewLog。只有完成评价才更新复习。耗时保留作诊断，不参与 FSRS 输入；无个性化参数优化。例句只在反馈显示，TTS 使用设备语音引擎，声音可用性和质量依设备而异；不是录音听写题。

## 恢复与撤销

数据库是权威来源，活动练习从服务端恢复，不依赖浏览器 Session ID。刷新可恢复核对页；未确认的答题/评价/撤销请求保存到浏览器并沿用原 payload 重试。断网不清除请求或自动跳题。这不提供离线题库、离线启动或离线同步。

同一体验用户只允许一个活动练习，创建时恢复已有 Session。用户行锁串行化多标签页修改。答题、评级和撤销有独立幂等请求；同编号不同内容冲突。最近一次答题可撤销或重新作答，日志软标记 undone；若已调度，在同一事务恢复完整原 card、计数和到期时间。旧版没有快照的已完成记录不能安全撤销。

## 页面与统计

保留 Glass 风格、深色模式、窄屏布局、减少透明度/动效适配。新控件有键盘焦点、表单标签、禁用状态与窄屏两列评级布局。数字 1–4 可选择选项或评级；输入中文组合、修饰键和焦点位于交互控件时不抢按键。

今日计数以北京时间 00:00 为界，显示已评价题数、独立记住、重学和待评价；包括自由练习，不以此声称正式保持率。分能力记录显示已练项与到期项。当前不包含句子分析、阅读听力专项、正式错题本、管理后台或备份同步。
