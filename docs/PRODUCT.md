# 产品行为（第一阶段）

目标用户为广东高中英语学习者。当前只提供五个**原创示例词条**，不宣称已经导入北师大版教材或高考词库。

首页显示待复习能力项、已练习词数；学习 Session 依次完成选择、主动释义和拼写，每个词义与能力单独存储复习记录。首页数据以及本轮学习进度均来自数据库。浏览器保存本轮 Session ID 以便刷新继续；数据库是权威数据源。

学生端采用柔和的半透明 Glass 界面，包含明暗主题、窄屏布局以及减少透明度/动效的系统偏好适配。视觉装饰不影响题目内容、答题状态或键盘焦点。

自由释义命中维护的别名时直接判对；不命中且非空时结果为 `pending`。待判题不进入错误统计，也不调整复习时间。空输入不可由页面提交，API 仍按错误处理。第一阶段没有 AI Worker，待判题仅保留原始回答等待后续人工/AI 处理。

提示可用于拼写首字母或主动释义；使用提示的正确答案记为正确并在日志中标记 `used_hint`，但不增加 `correct_count`，十分钟后仍需复习。此规则将在复习算法阶段替换。

验收范围：进入首页、开始 Session、完成三种答题、查看反馈、刷新继续、重复提交幂等、观察待判不改复习状态。没有账户、正式词库、FSRS、AI、错题本、管理后台或发音功能。
