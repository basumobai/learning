# S1 评分、修订与幂等

基于 main@de6f5ad；压缩包四份 S0 文档原样保留为历史审计基线。用户本次“根据压缩包的内容完成”为实施授权；不自动合并 #13/#15，不部署生产、不变更项目许可证。

实现：0016 增量迁移；管理员审核不可变逐题评分规则；多选少选/错选政策、多空、同义精确匹配、有理数等价、人工待评；提交事实与评分证据/outbox 原子写入。创建和提交相同键不同载荷返回 409，老客户端仍兼容。答案只在本人交卷后返回；规则不会发给未交卷学生。AI 参考评价独立存储，不能覆盖已审核规则的正式得分。旧反馈保留 legacy，不倒填可信评分。

数学仅支持有限长度有理数/分数比较；一般符号表达式和自动证明暂不启用。规则审批需要已发布题目、当前修订与人工核验说明。功能开关 `LEARNING_V3_SCORING=true`，默认 false；已固定规则的进行中练习在关闭开关后仍按原规则交卷。回滚只关闭开关和回滚应用，保留增量表，不 DROP/DELETE。

测试：新增评分单元、并发交卷、同键冲突、不可变证据及历史回看集成用例。实际执行结果见最终 `VALIDATION.md`，未运行前不视为验收通过。真实教材/高考规则、生产备份和外部 AI 仍需真实授权环境核验。
