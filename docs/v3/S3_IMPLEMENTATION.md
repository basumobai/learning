# S3 错因与迁移验证

0018 追加候选错因、学生事件历史；六科独立分类及输入失误标签。AI 候选通过现有有租约 Worker、模型身份组权限产生，原题引用和作答引用必须逐字核实；错误 JSON、无依据片段拒绝持久化。候选不是永久能力事实；学生可以确认、更正、待定、标已理解。相同事件键冲突检查、版本检查、按用户隔离。

输入失误更正会重算派生能力并保留评分和技能原事实；“已理解”与“新题验证”分别显示。原题再做使用原修订；新题只从同科、同主要知识映射、已审核评分的未做题选择，缺题返回明确说明。迁移作答与普通复答分开统计。

学生练习反馈加入 MistakePanel；错题查询 `/learning/mistakes?subject=&type=`。智能诊断 `LEARNING_V3_MISTAKES=true` 后需配置 mistake_diagnosis 路由，不强制依赖付费 AI；手工记录始终可用。本阶段没有真实六科教材与付费模型教学准确率证据。代码测试夹具不代表官方教材/真题。

S8集成后可在反馈卡片主动请求AI候选，使用当前身份组/个人模型选择；页面轮询原Worker任务，失败可重试，不自动把候选写成学生确认事件。
