## 5. 教学质量与真实外部依赖

建立六科**人工核验且有权使用**的固定评测集：英语长难句/阅读/听力信息保持/作文，语文阅读/作文，数学推导，物理建模，化学实验，生物遗传/图表。每条保存输入、标准答案/证据、评分细则、题目/知识修订、评审人、模型及提示词版本。自动确定性规则、AI 评判、人工复核分别标记，不能互称。

真实模型验收记录 TTFT、输出速率、成功率、成本来源及更新时间、事实/推导错误、引用准确率；费用预留与供应商账单分别展示。真实网盘验收需合法授权的 OpenList/夸克/百度样本，记录实际版本、请求数、仅下载批准文件及流量；没有授权不得以 mock 冒充真实成功。真实教材/试卷要核对具体版本、年份、来源、版权与分值规则；不能预装无授权材料。

## 6. 失败处理、报告与 PR 模板

每个阶段 PR 写明：**完成/未完成/兼容性/风险/实际运行命令/环境/测试结果/跳过项/回滚办法**。CI 失败不合并；涉及迁移必须有一次性 PostgreSQL 回归与旧数据保留证据。涉及正式评分、RAG、用户权限必须有负向安全用例。关键模型降级若教学质量不达标，应阻断或回滚任务路由，不因价格低直接替换。
