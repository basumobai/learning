# S8 弱网、恢复与交付

PWA仅缓存固定公开离线页和图标；不缓存 API、用户页面、题目答案、评分规则、PDF或录音。普通练习只保存本人原答草稿/冻结待确认提交，按账号和练习ID隔离；同键重放使用原答案，先核对服务器状态。跨设备草稿增加可选base_version，冲突要求学生核对，不静默覆盖。整卷不写本机题目/答案缓存，以服务端草稿和截止为准。退出清私有缓存，账号切换跨标签通知；同账号过期后重新登录可恢复原草稿。

新增管理员评分/映射、人工评分审查、教学评测和运行状态统一入口 `/admin/engine`。运维视图统计真实队列、outbox、缺失旧快照、数据库/原件规模和供应商报告Token；无TTFT/实付价格时明确未知。账户导出新增本人评分、知识、错因、回忆、句法、辅导、录音元信息和转写，不泄露未交卷原题解答。

备份使用 PostgreSQL 导出的同一事务快照生成 dump 与重要表逻辑校验，覆盖旧账号/FSRS/历史题和新增证据、原PDF/页图blob、录音；还包括本地PDF目录和原 .env/加密密钥。恢复演练仅创建随机前缀新数据库，不覆盖源库，校验后销毁副本；失败保留副本。现有内容哈希原件去重保持，未强推另一对象存储迁移。未来对象存储需单独增加备份适配。

CI在一次性完整Compose栈运行实际备份→新库恢复→逻辑/PDF/密钥核验。用户生产服务器未连接，生产恢复不宣称已演练。浏览器增加320至2560宽度、新页面和弱网重放；实际结果见 VALIDATION.md。新增代码均独立实现，现有依赖不变，仓库许可证未擅自变更。
