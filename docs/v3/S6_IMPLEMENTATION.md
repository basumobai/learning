# S6 审核引用、引导辅导与模型质量

0021 对正式资源的非题目正文建立 PostgreSQL 全文索引。检索还核对原解析页中的逐字摘录、物理页码、发布修订和当前资源审核状态；未审核 B 区、题目答案、本人未交卷题所用文档均不进入检索。引用按用户隔离，撤回或修订后重新检查访问。引用回链展示正式摘录和物理页码；含未审核题/答案的整个原 PDF 不开放给学生，以免提前泄题。

引导式辅导只在本人交卷后使用；原有安全通用提示可在交卷前使用。学生可选择小提示、疑问或完整讲解，也可跳过阶段。所有生成内容按结构渲染，不执行 HTML/JS。来源引用 ID 与逐字片段必须匹配候选，伪造引用/坏 JSON 拒绝保存。原消息不删除，最近8步按字符预算进入上下文，记录被选的步骤 ID、模型配置与提示词 hash；没有依据明确标为 AI 补充解释。

主观分数由管理员核验原答与原规则后追加 human_confirmed 评分事件；不覆盖原分/原答，非人工小题不能任意改分。新事件沿用评分 outbox，重算只消费最新有效评分；旧证据仍保留。

评测支持六科有权样例、核验词项、候选提示词/模型配置、既有 Worker 发起测试、端到端耗时、自动检查与人工复核。自动术语命中不当作教学正确率；非流式调用没有 TTFT 证据，实际费用需对账。`LEARNING_V3_QUALITY_GATE=true` 时，任务模型/提示词变更必须已有当前配置和提示词的人工通过评测；默认 false 便于先配置评测。`LEARNING_V3_TUTOR` 控制新辅导，默认 false。

本阶段无真实供应商实付或六科教学质量结论；新增权限、引用伪造、B区拒绝和人工评分追加测试。用户不能在未交卷时通过本题辅导/引用/历史取答案。
