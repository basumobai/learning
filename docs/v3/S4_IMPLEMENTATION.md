# S4 自主、强化、计划与回忆

0019 添加可回放选题日志、计划/跳过事件、独立回忆卡/复习/撤销。智能强化使用已发布且有审核评分/知识映射的题目；候选数、缺规则/映射、主动排除、历史曝光、证据状态、权重与策略版本完整存档。没有合适题目时返回空列表，不制造题源。自主练习仍使用原接口，新增安全的精确 question_id 过滤。

今日计划按广东教学日（Asia/Shanghai）生成，5–240分钟，用户可跳过；不强制打卡。`/progress` 汇总7天真实交卷、首答、提示、迁移与错题。时间是墙钟估计，明确不是专注时间；状态不编造掌握概率。

主动回忆卡从本人已交卷练习自建，不是已审核题库；与词汇卡及学科能力表独立。调度与四种结果预览只调用已有 go-fsrs/v4；错答/提示只允许 Again。同键不同评价409、版本保护；最后有效复习可原子撤销，原事件保留。

智能强化由 `LEARNING_V3_PLANNING` 独立控制。高阶证明/建模通过 S3 新题迁移，不转换为记忆概率。暂不启用无样本的个性 FSRS 参数优化。真实教学效果、完整教材映射继续需要独立核验。

S8集成回归将策略升级为 `selection-v2`：使用已审核的前置图、本人可信失分证据、最近确认/更正的非手滑错因、距离上次证据的时间，以及审核题目的难度和本次科目/题型分布。候选日志记录题目、规则、知识映射修订与实际权重；不会仅因经过14天就认定遗忘。计划待复习量按学生选定科目计算，词汇待复习只计入英语范围。数据库用例覆盖前置优先、循环关系拒绝、错因理由、重放与跨账号隔离。
