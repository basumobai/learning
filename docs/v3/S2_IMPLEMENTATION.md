# S2 知识与能力证据

依赖 S1。0017 复用 learning_terms，新增逐小题、主要/辅助/前置/应用映射的不可变修订，开始练习时固定映射；前置关系拒绝跨科与环。只消费 verified_rule/human_confirmed 评分，legacy、未确认 AI 与主观题不写可信能力结论。

沿用现有 Worker 消费 S1 outbox，PostgreSQL 事务、行锁及唯一键保证重投不重复。独立、同题重复、平台提示、迁移证据分开；多主要知识点的失分标 ambiguous，辅助/前置不计负向独立证据。状态用 limited/learning/consolidating/basic 表示证据阶段，不显示伪造掌握百分比。物理/英语等六科复用现有知识目录，未授权教材映射不预装。

`LEARNING_V3_SKILLS=true` 独立启用；关闭后停止消费，事实仍在 outbox。学生接口严格从当前账号读状态/证据。安全提示为不包含答案的通用作答策略，先持久化提示事件再返回；不宣称是 AI 提示。未来新增具体提示时必须延续该证据流程。

新增数据库用例覆盖独立/复答/提示分离、消息重放、证据不可变与跨用户隔离。真实执行结果汇总于 VALIDATION.md。
