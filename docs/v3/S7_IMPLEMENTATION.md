# S7 广东分年份整卷与真实语音渐进接入

0022 增量扩展现有 learning_exam_rules 的 duration_seconds/total_points。只有已核验广东规则、具体适用年份、每板块小题数/板块总分、整卷总分/时限一致才组卷；材料题组保持完整，候选/动态规划有界，缺题明确拒绝，不补造题源。所有卷标“平台模拟卷”。不预装未核验官方年份规则。

复用 learning_attempts、题目/评分/知识修订，保存整卷规则与题目快照。服务端确定截止；整卷交卷在一个事务内评分/outbox，同键不同载荷409。截止后只接受服务器保存的草稿，现有 Worker 自动关闭逾期卷；历史/资料/AI/导出及单题提前交卷在整卷进行时受服务端统一限制。客户端提供恢复、自动草稿、题目导航、分板块复盘与明确标为墙钟的整卷耗时。

ASR模型作为明确的第三种模型用途，沿用服务商、密钥、身份组授权。听说任务可选上传本人录音，再调用兼容 `/audio/transcriptions` 的服务。录音原件和转写按本人隔离、哈希/请求键持久化；同键重放不再次调用。转写标“待核对”，供学生修正后填写作答。现有TTS不变，没有将 ASR 文本冒充官方口语或专业发音分。

`LEARNING_V3_EXAMS` 默认关闭。真实音频/模型收费、发音质量及具体广东年份卷型仍需真实合法材料和供应商核验；本阶段只实现可接入路径，自动测试使用合成音频和 mock 供应商，绝不声称实付模型验收。
