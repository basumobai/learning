# 广东高考题型与教材归档

## PDF自动归类

将PDF放到 `data/pdf/` 后，在多学科管理刷新目录、选择文件并导入。**不是文件一放进去就无人值守扫描或发布**。题目、答案在同一PDF时可选择同一文件。

1. 提取原生文本，扫描页单独OCR。
2. “PDF学科与教材归类”任务根据封面和各页文字提出学科、实际来源版本、册次、资料类型、把握程度与PDF逐字依据。
3. 选择资料，在“确认AI识别的教材范围”核对原页，确认后才启动章节任务。没有封面、扫描模糊或跨学科时，不默认当英语或编造版本；混合学科建议先拆分PDF。
4. 核对册次、教材章/Unit和小节/Lesson及页码，再提取题干、答案、配对，审核草稿后发布。

归类与OCR、目录、题干、答案、配对分别配置模型和提示词。归类任务首次新增时继承原目录任务的模型/后端，既有自定义提示词不覆盖。识别失败后可修复配置重试，也可核对原件人工确认；运行中不能同时改归属。

AI归类不保证完全准确：每页使用文字节选，模型的“较高/一般/较低”是自述，不是校准的准确率。引用页码或原文不匹配会被拒绝，不确定信息应留空。没有原目录的综合卷不能凭题目猜一个确定教材章节。

## 教材与题型分别筛选

练习页分别选择 **学科 → 教材版本 → 册次 → 教材章/Unit → 小节**，再选择高考题型。册次与“高二上”等学期独立保存；不同册中的同名Unit 1通过册次过滤隔离。题型和册次显示实际已审核发布题量，未导入的册次显示0题。

英语固定 **北师大版2019新教材**：必修第一、二、三册，选择性必修第一、二、三、四册；“综合复习”用于跨册资料。不会把人教、外研、译林或2003旧版教材直接改标为北师大版。未指定教材版本的高考综合卷可归入北师大课程的综合复习，原始识别建议仍保留。

其他科目按实际封面/版权页及学校选用情况核对，不能由“广东高考”推断全省使用同一出版社。册次列表是输入候选，其他版本可按封面填写真实册次。章与小节来自导入目录和正文，由管理员确认；平台未预装一份覆盖全广东所有版本的完整教材目录。

已有资料、题目与旧分类保留，不批量改标旧教材字段。新PDF导入（包括手动提供科目的情况）都先确认归属。

## 六科题型框架

| 学科 | 高考板块与练习细分 |
| --- | --- |
| 语文 | 现代文Ⅰ信息类/Ⅱ文学类，文言文、古代诗歌、名句默写、语言文字运用、材料作文 |
| 数学 | 单选、多选、填空、解答；知识模块可交叉，保留小问、推导及原题评分依据 |
| 英语 | 阅读A–D篇、七选五、完形、语法填空、应用文、读后续写；广东单独听说A/B/C |
| 物理 | 单选、多选、非选择；实验与计算分别归类，保留图像、装置与过程 |
| 化学 | 单选、非选择；细分实验、工艺流程、反应原理、有机推断合成、结构性质及跨模块综合 |
| 生物学 | 单选、非选择；细分填空简答、实验探究设计、图表信息分析、遗传推理及跨模块综合 |

化学、生物细类是训练标签，可在一道题中交叉，不表示官方规定“每类恰好一道”。平台保留原PDF题组与原始分值，不将阅读文章题材误当题目学科，不按教材章节编造官方固定题量或比例。语文专项的30分钟/超过850有效汉字等平台目标与正式考试规则分别标注。

依据核对于2026-10-17（UTC+8）：

- [广东省2026年普通高校招生工作规定](https://szeb.sz.gov.cn/attachment/1/1713/1713627/12781791.pdf)：语数外使用全国卷，物化生为广东选择性考试，不是合格性考试。语文150分钟，数学/外语120分钟，物化生各75分钟；语数外每科150分，物化生各100分。广东英语笔试原始成绩按13/12转换，加听说成绩并四舍五入；听说卷面分除以3并四舍五入。
- [教育部2026年全国卷试题评析](https://www.moe.gov.cn/jyb_xwfb/xw_zt/moe_357/2026/2026_zt08/mtbd/202606/t20260610_1440059.html)：按全国卷学科任务组织，不将其他省选考试卷或旧题型配额当成本年全国卷。
- [北师大教材出版方电子教材入口](https://www.100875.com.cn/show/downloadAnnouncement.html)、[选择性必修第一册Unit 2教学材料](https://flts.bnu.edu.cn/node/15483)、[Unit 3教学材料](https://flts.bnu.edu.cn/node/16588)：区分新旧版与册次，教材正文不随仓库分发。

未来考试不能直接认定沿用2026配置；题量、分值、顺序以相应年度正式试卷为准。当前为专项练习与题库结构，不宣称已有完整全科整卷模拟或官方评分。
