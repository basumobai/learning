# 判分与 AI 边界

当前没有 AI、Embedding 或后台 Worker。主释义/维护别名精确匹配直接判对；其它非空中文释义为 pending。学生在反馈页对照参考答案自评，记录 initial_result 和 resolved_result；不能将此描述为语义识别或 AI 判分。

未确认的 pending 不更新复习状态。自评正确且无提示后可选择困难/记住了/很轻松；自评错误或使用提示只能重学。所有调度都在用户确认评价后进行。

未来 AI 判分须明确 provider、超时、重试、证据、置信度和人工纠错入口；只能在授权范围的测试环境接入，不向外部服务发送未获授权的个人信息或生产密钥。
