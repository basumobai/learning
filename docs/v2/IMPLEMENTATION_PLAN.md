入口：[审计报告](P0_AUDIT.md) · [架构/迁移/API 设计](ARCHITECTURE.md)

## 1. 实施顺序与阶段出口

| 阶段 | 具体交付 | 必须通过的验证 | 出口条件 |
| --- | --- | --- | --- |
| P0 | 当前代码/迁移/API/页面/PR 审计，复用边界、架构与迁移、风险和本计划 | 核实 main SHA 与远程 CI，执行可运行的基线测试 | 事实/设计/未实现项明确分开；无业务代码变更 |
| P1 | GET 模型发现、OpenRouter 目录、元数据来源、可视多选/批量启停/组授权、任务候选与失败路由 | 目录协议模拟、授权撤回、能力未知、排序/跨页选择、401/429/5xx/超时与费用规则、迁移旧模型/组 | 保存服务商后无需查 ID；手动备用正常；降级不越权、不悄悄超预算 |
| P2 | 统一管理布局，普通操作去重复密码，高风险动作认证，首次强制改密、交互恢复命令 | 普通用户/未登录/跨站/缺 CSRF 拒绝；高风险重置/提权保护；首次与旧账号区别；会话撤销；旧 URL | 后台常规操作不再输入密码，服务端权限与密钥安全保留 |
| P3 | 通用资源/不可变原件/来源、A/B/C 状态、增量目录扫描、共享管理域、独立 Worker、租约/重试/取消/恢复 | 原子入库、同 hash 不同来源、重命名、并发管理员、Redis丢失/重启、过期Worker写入、取消、迁移与兼容读取 | A/B/C 实际流转可恢复；单份 PDF 可进 A；仅此阶段不宣称已有智能分类 |
| P4 | 有预算的元数据/代表页/少量 OCR/AI 分类、B 筛选/批改与证据、专题和教材分离 | 下列场景1–6的轻量部分；检查实际调用页/字/token/图/耗时；错误名称与低质量扫描；人工覆盖 | A→B 不走全文 OCR、不逐题提取；独立专题无强制教材字段 |
| P5 | 夸克/百度分享适配验证、目录分页、仅元数据推荐、批准下载、进度/重试/取消/限流、A 区衔接 | 场景7及下载故障；真实授权两类分享样例、至少一份 PDF；未选文件网络请求为零；目录变化与未知大小 | 两适配器能力逐项如实标记；未验证不可隐藏成“通用网盘支持” |
| P6 | 教材/专题/试卷/混合策略，全文OCR按需、分块/checkpoint、内容单元和来源、缺答案草稿 | 场景1–6深度部分；混合板块、重复题号、共用材料、图表/公式、多小题、缺答案 | 有可审核产物；失败部分可独立恢复，原件不变，不编造答案 |
| P7 | 多维题库、教材/知识点多对多、规则版本、来源真实性状态、可视编辑/审核/批量发布、历史题目快照 | 题型/答案与发布校验、审批修订冲突、未审核隐藏、无章节题可练、旧attempt版本可读、规则分年 | 正式库只读通过审核的具体版本；题目和讲义按内容类型校验 |
| P8 | 完整多端交互、端到端集成、安全/恢复/升级验收、简洁 README 与详细 docs | 下列全矩阵 + 原词汇/FSRS/AI教学回归 + 真实Compose升级/恢复 | 功能清单、证据、未完成边界齐全；代码PR可审阅，生产部署另行安排 |

严格按 P1→P8 开放能力。P8 的 UI 和回归要求从前面各阶段同步执行，不能最后才检查手机。P5 的外部适配风险研究可提前只读开展，但不能先另造一套脱离 P3 的下载入库系统。

每阶段独立提交实现与测试记录；必要时分多个小 PR。开发分支以当时最新 main 创建，合入前重新核对基线差异；本任务不直接改/合并 main、不部署生产、不删除旧分支或生产数据。P0 文档 PR 只承载这三份报告。

## 3. 八个核心场景的可测断言

用固定、可合法使用的测试 PDF/目录清单保存物理页、文字、知识点和预期证据。CI 使用自制/授权夹具及模拟供应商验证契约；真实模型准确性另用合法教材/真卷样本人工抽检，记录模型、提示词版本、预算与失败率。不能把自制两页 PDF 测试当作已经识别真实教材或官方试卷。

| 场景 | A→B 必须断言 | B→C / 后续必须断言 |
| --- | --- | --- |
| 1 北师大英语选择性必修一教材 | 实际封面/版权/目录证据支持英语/北师大2019/册次；只处理预算内页面；不提前提取全文 Unit | 原件真实 Unit/Lesson与正文、练习；与正确册次关联，缺目录不编造；教材无独立答案也能审核正文 |
| 2 英语语法综合练习 | 识别语法专题与多个语法点；textbook_alignment=no或unknown；版本/Unit允许空 | 逐题关联定语从句/非谓语/虚拟语气；缺答案题进入待审核，不能因没有教材章节被丢弃 |
| 3 2025广东高考英语真题 | 可识别英语考试候选与年份线索，authenticity仍未核实；不只按文件名确认真题 | 对照实际元信息/卷结构/来源；绑定2025适用规则；来源不足显示未核实，模拟卷伪装名称不能变官方 |
| 4 物理电磁感应专题 | 物理/知识点专题；知识点证据；无教材要求 | 小题/实验/计算/图像按实际内容拆分；多知识点和插图来源保留 |
| 5 文件名英语、内容数学 | 至少实际内容核对；改判数学或待确认；不能因名称清楚免核对 | 以后深度输出不得被旧英语缓存污染；修正保留原因与证据 |
| 6 语法/阅读/词汇混合 | 多专题/综合或混合标志和抽样覆盖；不足则待确认 | 生成多个逻辑单元，原PDF hash不变；材料和小题关联正确，无物理拆文件要求 |
| 7 网盘大量不同资源 | 下载前只给 AI 目录元数据；推荐不触发下载；显示已知/未知字节和重复提示 | 仅批准集合下载；未选文件没有下载请求；校验完成进A，再走实际内容轻量识别 |
| 8 异常恢复 | 原件导入与去重事务；OCR失败/AI超时有阶段/原因/预算记录 | API/Worker/Redis重启、重复消息、超时租约、网络断连、取消与旧结果迟到都不丢原件、不重复题目/发布、不覆盖人工修订 |

## 4. 可靠性与安全验收细项

| 类别 | 场景/判定 |
| --- | --- |
| 幂等 | 同资源重复扫描/不同管理员同时导入；同哈希不同来源；同名不同内容版本；同题号不同小节；同幂等键不同输入应409 |
| 持久化 | 数据库提交后Redis投递前崩溃、投递后标记前崩溃；Redis flush/重建；任务完成后ack前崩溃；每种都能从DB恢复 |
| 租约 | Worker心跳停、旧Worker恢复、取消时结果同时到达；所有页/题目/分类/审核写入拒绝旧generation |
| 检查点 | 深度任务处理超过旧10分钟，按块恢复；已成功页不重复OCR；策略/规则变更创建新run而非混用旧checkpoint |
| 预算 | 页面/字符/token/图片/耗时/最大尝试/费用各自超限；未知报价不当零；重试和备用也计算；暂停恢复不重置总预算 |
| 模型安全 | API Key不在浏览器响应/日志/AI内容；目录同步不自动授权；停用和撤权即时影响后续调用；供应商回退不越权限/价格策略 |
| HTTP | 登录、普通管理、资源审批均校验角色/CSRF/Origin；GET不触发有副作用的同步；SSRF、DNS私网、跳转私网、跨域凭据转发拒绝 |
| 分享安全 | 失效/提取码错误/分页循环/目录变化/恶意文件名与提示注入；AI只能返回白名单ID；未知大小、磁盘满、下载不完整、Range不支持可恢复 |
| 文件 | 原始只读文件从不被任务清理；路径跳出、符号链接替换、非普通文件、伪PDF/加密PDF、超页数/超尺寸图都受限 |
| 审核 | 缺答案、矛盾选项、OCR模糊、原文引用不存在、错误页码、规则版本未知不可自动发布；审批后编辑必须重新审核 |
| 隔离 | 学生看不到A/B/C、未发布答案、他人job/attempt/个人API；其他管理员按共享管理域接手资源但不能读学生私有任务 |
| 账户 | 新初始管理员被强制改密；旧用户不被误锁；重置撤销会话；最后管理员/自身停用保护；恢复命令无密码回显、写入审计 |
| 迁移 | 0007→各阶段、重复启动、任务运行窗口、失败回滚、双读；账号密文/PDF hash/词库FSRS/旧发布题/作答保持可读 |

PDF 解析和渲染 Worker使用非root、进程超时及内存/CPU/临时目录限制；提取进程不得直接获得网盘凭据。此项针对任务书要求的资源限制，不是允许从文档执行指令。

## 5. 多端验收

沿用现有 Playwright 模拟 API 测试，新增真实临时 API/数据库的端到端测试。视口至少包括 320/390 手机、844×390 横屏、600 分屏、834 平板竖屏、1194 平板横屏、1440 桌面以及1920大屏；浏览器缩放、系统字体放大、触屏和键盘均检查。

必须实际完成：服务商保存后模型弹窗多选、批量授权/停用、A/B/C筛选与跨页选择、修改标签、PDF页码与解析对照、网盘目录多选和下载取消、失败重试、页面刷新恢复。手机不得只显示摘要或依赖悬停。窄屏对照可以切换原文/结果，必须保留页码/编辑草稿。

检查横向溢出、点击目标、焦点恢复、键盘可达、加载/空状态/错误状态、长文件名、数千目录项/模型项分页与虚拟化、批量工具条遮挡和减少动效。大屏浏览器与电视可完成基本键盘导航；不把支持大视口表述成已验证所有电视系统。

## 6. 每阶段记录模板与最终交付

每阶段记录：基线/提交、迁移编号、接口与页面变更、实际运行命令、结果/环境、模拟与真实依赖的区分、回归范围、遗留能力/风险、回退方法。记录放 docs，不把失败检查删除后称为通过。

最终交付应包含：

- 独立开发分支与可审阅 PR，阶段提交和CI链接；不得自动合并。
- README仅说明安装、升级、初始改密与核心入口；复杂设计/运维放docs。
- 数据兼容及备份恢复演练记录；不代替生产部署批准。
- AI/网盘适配器能力矩阵，支持/未验证/不支持明确区分；真实调用的模型、来源时间、费用与质量边界。
- 八个场景和旧单词学习、FSRS、限时四选一、按需讲解、句子/听力/TTS、多模型作文、个人数据隔离的回归结果。

## 7. 风险登记与实施处理

| 风险 | 影响 | 处理和触发点 |
| --- | --- | --- |
| 夸克/百度分享API不稳定或账号权限不足 | P5无法完整验证，不能承诺上线支持 | P5适配验证先于完整UI；真实授权样例通过后再开放；失败明确能力缺口 |
| 元数据与内容冲突、抽样覆盖有限 | A→B可能误判或漏掉少数混合主题 | 最少内容核对、分散抽样、证据/覆盖展示、低信心待确认；深度阶段再复核 |
| 模型能力/价格缺失或变化 | 选到不可用模型、费用超预期 | 目录快照+明确逐模型测试，未知不当支持/免费；调用前能力和预算复核 |
| 历史资源数据不完整 | 错误回填教材、阶段或审核状态 | 保留legacy原字段，保守映射并待复核；不AI补造旧数据 |
| 旧任务与新Worker并发 | 重复调用、旧产物覆盖新结果 | 可控切换窗口、租约与所有副作用CAS、策略修订、测试恢复 |
| bytea与页图增长 | 数据库/内存/备份成本 | 保留上限、hash去重、分块、压测；对象存储迁移另立边界，不在启动时全库拷贝 |
| 普通接口去密码时误删权限 | 管理越权 | 先建立会话/角色/CSRF负向回归，再去密码字段；高风险专用认证 |
| 题型规则被当永久模板 | 未来年份或不同卷误归类 | 年份/考试类别/来源和审核版本，未知配额不硬编码 |
| 实际内容含公式/图/缺失答案 | 错题或伪答案发布 | 保留图片与页码、草稿可不完整、发布验证和人工审核 |
| 改造影响旧学习记录 | 学习/复习/交卷不兼容 | 保留ID与数据、版本快照、每阶段旧功能回归，不在本任务清理历史 |

P0 没有阻止实施的内部架构未知项。P5 真实分享兼容、P7 完整教材/逐年真卷规则和真实 AI 质量仍是验证门槛；可以完成其他阶段的代码与模拟测试，但不能在这些门槛未完成时声称整个 v2 已交付。
