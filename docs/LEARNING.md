# Learning：多学科学习平台

本分支基于已完成的账户、FSRS、听力训练，以及 `codex/apple-frontend` 的界面成果。原英语词汇学习移到 `/english`，原账户、数据库、Cookie 名称和环境变量保留，避免改名导致已有部署丢失数据。Android 暂不开发。

## 使用流程

1. **管理员准备模型**：`/admin` 添加公开 HTTPS OpenAI 兼容服务商、聊天/视觉模型和权限组；`/admin/learning` → AI 提示词与模型，为目录识别、提取、动态讲解、追问、主观题评价、作文评审分别配置。默认提示词已提供，可编辑与恢复。保留原聊天、句子、听力的用户模型选择；这些入口现在也读取管理员提示词。
2. **接收资料**：同时提交题目 PDF 和答案 PDF，选择科目、教材/册次、学期；可本地上传，也可通过管理员配置的 WebDAV 资料根目录读取。每份最多32MB、200页。反向代理需允许至少70MB请求并配置适当上传超时。扫描页传给视觉模型识别，文本页保留可提取文字。
3. **选章节**：系统分批识别目录与小节，显示物理页码和不确定信息。管理员核对/补充题目页、答案页，可多选小节。长章拆成小节，每小节最多8页题目+8页答案；每个小节独立排队，目录分批进度持久化，失败可以重试。
4. **审核发布**：只识别选中小节。保存共用材料、各小题、选项、分值、原始答案引用、详细解析、来源物理页和插图裁剪框。题目先为草稿，管理员对照原 PDF 核对并可编辑数据，再发布。重复提取按文档内原题号去重。模型给出的插图裁剪、题号对应、答案和语义均需审核；不能把模型输出视为已核实的教材。
5. **学生练习**：首页选择语文/数学/英语/物理/化学/生物，先选题型，再按教材、学期和章节多选范围。选择题、多选、填空、作文/解答题使用同一题目组结构。支持共用阅读文章及其多道小题。
6. **按需讲解**：学生打开一道题后，浏览器才请求该题后台生成；入库不生成动态示例。题目打开后仍可正常作答。交卷前服务端不返回正确答案、解析或动态讲解；交卷后展示参考解析、逐步荧光标注、圈注、插图强调和内嵌追问。

所有实际学习资料均由管理员导入；没有附带真实教材、试卷或完整六科题库。题库为空的范围会明确提示。原五个示例词继续用于开发。

## 广东题型范围

仅提供广东高中/高考方向的分类，不混入其他省份专用卷型或中考的“语法选择”。英语分类为阅读理解、七选五、完形填空、语法填空、应用文、读后续写、英语听说。语文为现代文/文言文/诗歌/默写/语言运用/作文；数学为单选/多选/填空/解答；物理为单选/多选/实验/计算；化学、生物为选择和非选择。细分题型与实际材料的分值由审核后的题目数据决定，未硬编码每年整卷题数。

这是**专项训练**，尚未实现整套广东高考试卷编排、英语听说正式录音与口语测评。保留的原创听力四选一是基础听力训练，不宣称等同广东正式听说题型。英语听说的正式内容可按资料入库，但当前作答控件为文本。

核对来源（2026-10-16）：

- [广东2026英语听说成绩通知（广州招考官方转载）](https://gzzk.gz.gov.cn/gkmlpt/content/10/10764/post_10764726.html)：英语听说单独计分，与笔试合成。
- [广东发布：2026全国一卷语文作文题](https://m.thepaper.cn/newsDetail_forward_33328097)：官方原题写作要求为不少于800字。
- [教育部教育考试院英语试题评析](https://www.neea.edu.cn/html1/report/22012/3104-1.htm)：语篇阅读、语言运用和写作的命题导向。

用户指定的**语文作文30分钟、有效汉字超过850**和**语文阅读30分钟**是平台训练规则，并非官方完整考试时限或字数要求。有效汉字至少851个，标点、字母、数字不计。草稿带递增版本，延迟到达的旧请求不能覆盖新草稿。截止后提交仅使用服务端在截止前保存的草稿；未达字数标为未完成，不提交评审。页面每1.5秒尝试保存变更，网络中断未保存的部分不能补记为截止前作答。

## 极速四选一

- 英选中和中选英，选项位置每题重新随机。
- 普通：整题6秒，四个选项差异明显。
- 困难：整题3秒，恰好两个近似选项，正确答案在这对选项中。
- 绝望：整题3秒，四项近似，每项带词性。
- 管理员按词义编号生成选项集，模型返回审核理由与近似组，结构校验通过后仍须人工批准。语义相似性和答案唯一性不能由组标签证明。
- 答题期间不请求模型，不泄露正确项或近似组标签。截止以服务端时间为准；刷新、停止连做、并发开始不会延长已有题目时间。提交一次即确定正误，超时记错并进入下一题。此模式记录独立训练成绩，不替代 FSRS 的记忆评级。

## AI 上下文与缓存

动态讲解传当前题目组、对应参考答案和当前题目的裁剪插图；不传整本PDF。返回的JSON受协议约束：原文、Unicode码点范围的成分标记、步骤、被引用插图ID及总结。普通文本用React转义渲染，不执行模型HTML/JS/CSS；LaTeX公式由KaTeX转换为带MathML的标记，关闭trust并限制展开次数、尺寸及单个公式长度。支持暂停、前后切换、进度条、静态步骤列表、减少动效及深色模式。

追问只传当前题目组、当前步骤、该次作答、参考解析，以及当前步骤最近两轮对话；不传其他题、其他章节或其他用户记录。模型调用没有应用调用次数/对话次数配额。输入大小与并发约束用于限制单次工作量，不是付费额度。

讲解缓存按账户、题目版本、提示词版本、个人接口选择区分；更改个人接口后使用新缓存键。对话和任务结果按账户隔离。管理员修订题目会升级版本，旧版本练习会提示重新选题；历史记录仍保留在数据库，但当前页面不支持继续打开旧版本题目。任务结果和失败信息持久化，失败可重试；崩溃的任务12分钟后可重新领取。外部模型计费不保证 exactly-once，极端崩溃情况下重试可能产生新的供应商调用。

## 作文与个人 API

支持网页输入、UTF-8 TXT、DOCX。旧版二进制 DOC 请先另存DOCX。只提取正文，不执行宏，也不打开外部链接。

平台作文配置为2–5个独立评审模型，同时评审，再把原文与评审结果交给主审。保留独立分数、原文证据、理由与建议；主审给出0–60参考分、分歧处理和修改建议。一位评审失败或返回无效结构时任务失败，不伪造缺失结果。

学生可以在设置中配置自己的公开HTTPS OpenAI兼容基础地址、Key、常用/主审模型，并可填至少两个独立评审模型标识；做题前勾选“使用我的API”。密钥用服务器 `APP_ENCRYPTION_KEY` 加密，设置页只返回已配置状态。个人API与管理员云盘凭据分别加密、隔离。真实模型费用由对应接口承担。

## 可选 Codex CLI 入库

API方式可独立完成全部入库，不需要Codex。选择CLI时使用独立 `codex-runner` 服务，网页API不执行终端命令、不接收Codex账号密码。云盘文件由受限WebDAV读取器取得，Codex只收到当前批次页图和文字。

1. 在 `.env` 设置固定 `CODEX_VERSION`（必须支持以下参数）与至少32字符随机 `LEARNING_CODEX_RUNNER_TOKEN`。
2. 先构建：`docker compose -f docker-compose.yml -f docker-compose.codex.yml build codex-runner`。
3. 管理员在独立容器完成自己的CLI授权，例如 `docker compose -f docker-compose.yml -f docker-compose.codex.yml run --rm codex-runner codex login --device-auth`。不要把登录资料提交到Git。根据自己的账号、供应商和使用条款配置；本实现不代替授权或承诺可用额度。
4. 启动可选服务：`docker compose -f docker-compose.yml -f docker-compose.codex.yml up -d`。
5. 管理页面把“目录识别”“题目与答案入库”切换Codex，可指定模型标识；学生侧的解释/追问/评审继续使用API。

服务使用 `codex exec --ignore-user-config --ephemeral --sandbox read-only --skip-git-repo-check --image ... --output-last-message ... -`，不使用shell拼接，也不读取共享对话历史、生产目录或Docker socket。容器只挂载独立CLI授权卷，页图临时文件自动清除；拒绝远程图片URL、过大请求和非预期输入。CLI的只读沙盒仍需宿主环境支持；失败会停止，不自动放宽权限。实际CLI登录/付费模型调用未在本次测试中执行。

[官方非交互执行文档](https://developers.openai.com/codex/noninteractive) · [官方CLI参数](https://developers.openai.com/codex/cli/reference/)

## 备份与验证

新增迁移 `0004_learning_platform.sql` 只增加表，不删除原数据。PDF原件、渲染页、裁剪插图、题目、作答、任务与加密配置保存在PostgreSQL。备份数据库和服务器加密密钥；存储会随资料增长。保留现有数据库名/卷名，仓库更名后不要新建空卷替换旧卷。

- `go test -race -count=1 ./...`，配置 `TEST_DATABASE_URL` 运行真实迁移和隔离schema测试；PDF测试需要Poppler。
- `go vet ./...`、`go build ./cmd/api`。
- Web：`npm ci && npm test && npm run build`。
- 浏览器：`npx playwright install chromium`，启动生产构建后 `UI_BASE=http://127.0.0.1:3007 npm run test:ui`；使用模拟API，不消耗模型额度。
- CLI协议：`python -m unittest discover -s services/codex-runner -p 'test_*.py' -v`。

真实供应商音色、OCR准确度、扫描版复杂公式、答案匹配与插图裁剪质量、Codex授权及部署仍需配置实际服务后验证。当前不自动合并主分支或部署生产。
