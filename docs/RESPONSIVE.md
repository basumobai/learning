# Learning 多端布局与操作

2026-10-16。手机、平板、电脑使用同一套页面与作答状态，不按机型复制页面。按可用宽度、视口高度和输入能力调整布局；横竖屏和分屏变化不重建题目，不触发额外AI生成。

| 场景 | 导航与内容 | 输入与操作 |
| --- | --- | --- |
| 手机竖屏、平板窄分屏 | 底部导航；范围、题目、反馈依次排列 | 主要操作与导航至少44px；模型与历史记录默认折叠；输入框不自动抢焦点 |
| 平板竖屏、中等宽窗 | 顶部两行导航；阅读与反馈采用单列 | 防止挤窄正文；支持横向滑动管理功能与数据表格 |
| 手机短横屏 | 导航随页面滚动；挑战计时/题干与四个选项并排 | 开始后自动定位题目，四个选项同时可见，停止按钮保留在题内 |
| 平板宽横屏、电脑宽屏 | 宽屏可并排范围与模型、题目反馈与讲解 | 鼠标/键盘可用；细指针保留拼写框自动聚焦、1–4答题快捷键 |

## 连续操作

- 练习开始、提交后定位当前题目或反馈标题；反馈/动态讲解提供页内跳转。旋转屏幕后保持作答、已选模型、阶段和用户手动展开状态。
- 视口足够宽时默认展开可选模型/对话历史，窄屏默认折叠。内容只隐藏，不卸载；用户手动展开/收起的选择优先于视口默认值。
- 词汇练习只对细指针自动聚焦拼写输入框；触控用户点按后再弹键盘。VisualViewport/窗口收缩与输入焦点结合判断软键盘；窄屏底部导航在键盘打开时让位。保留系统页面缩放，不写最大缩放限制。
- 作答仍每1.5秒自动保存；切到后台、点击站内其他页面或离页时补发带CSRF与版本号的草稿。keepalive仅用于60KB以内的正文，避免浏览器共享64KiB上限；更大的作答继续依赖常规保存。关闭进程、离线或操作系统强制终止不能保证最后一次请求送达。
- 极速挑战开始后收起设置、定位题目；窄屏使用2×2选项。后台切走会停止自动连做。当前题的服务端截止时间保持有效，恢复不会延时。
- 题目插图与动态步骤插图可点按放大到300%，滚动看细节，支持Escape关闭并返回原控件焦点。使用原生dialog隔离焦点；键盘滚动数据表格、范围滑块均可操作。
- 学习子页面与管理员子页面均正确高亮所属主导航。首次必须改密的账户只显示设置入口，不加载个人API配置；普通账户不显示管理员入口。

## 验证

生产构建下11项前端状态/安全测试、34项既有学习流程检查，以及398项多端浏览器检查通过。所有API/模型响应为确定性原创夹具，不调用付费模型。共享夹具由每个浏览器上下文独立初始化。

| 场景 | CSS视口 |
| --- | --- |
| 小手机 | 320×640 |
| 手机 | 390×844 |
| 手机横屏 | 844×390 |
| 平板竖屏 | 834×1112 |
| 平板横屏 | 1194×834 |
| 平板分屏 | 600×900 |
| 导航边界 | 701×900 |
| 电脑 | 1440×1000 |

矩阵覆盖首页、专项练习、挑战、词汇学习、AI对话/句子、词库、设置、管理员账户/题库和登录；逐页检查横向溢出、当前导航、触控区域和文本控件；包含长英文词条与窄屏内容换行。额外覆盖旋转/分屏保持作答与选择、触控和桌面输入焦点差异、键盘答题、图像放大/滚动/Escape/焦点返回、后台停止连做、模拟键盘视口收缩与导航让位、带CSRF的离页草稿、普通用户与首次改密流程，以及720px电脑窄窗。

测试使用Chromium与模拟触控；软键盘通过浏览器视口契约模拟。HyperOS/iPadOS/Safari的真实系统键盘、设备帧率与系统手势未进行实机验证。

运行：`npm test && npm run build`，启动生产Web后 `npm run test:ui`；单独检查设备场景可用 `npm run test:devices`。现有GitHub Web CI自动执行两组浏览器检查。
