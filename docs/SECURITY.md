# 账户、密钥与数据安全

## 身份与登录

没有公开注册；账户由管理员创建。密码采用 Argon2id，随机 16 字节盐、19 MiB 内存、2 次迭代、1 线程、32 字节摘要。密码 15–128 字符，支持长短语，不要求机械的字符组合。不存在的用户走相同哈希验证，登录失败返回统一提示。失败登录有账号/网络的临时防暴力破解措施；这只针对认证失败，不是 AI 调用额度。

登录使用 256 位随机不透明会话，数据库仅保存 SHA-256 摘要。Cookie 为 HttpOnly、SameSite=Strict；HTTPS origin 使用 Secure 和 `__Host-` 名称、Path=/，不设置 Domain。浏览器不把登录凭据或会话放入 localStorage。会话绝对有效期 7 天，学习用户闲置 24 小时、管理员闲置 1 小时失效。活动写回每五分钟一次。

写请求验证配置的 APP_ORIGIN 与会话派生 CSRF token；浏览器使用 X-CSRF-Token，token 只在内存中保存。无 Origin 的受信任 API 客户端还需 X-ELS-Client:web；没有跨域 CORS 授权。页面禁用 frame embedding、object 插件，设置 nosniff 与来源策略。

首次登录/管理员改密后仅允许身份读取、改密和退出。用户改密必须提交当前密码，事务内撤销所有会话。管理员停用、改角色或重置密码也撤销对应会话。可退出其他设备。管理员敏感写入再次检查当前密码与管理员状态；禁止停用或降级自己，禁止停用/降级最后一个启用管理员。

## 两步验证

用户可以绑定 RFC 6238 SHA-1/六位/30 秒验证器。绑定需要当前密码和有效验证码；待绑定密钥十分钟过期。验证器密钥 AES-256-GCM 加密。允许一个时间步的时钟偏差，保存最后已使用步并在事务内拒绝重放；开启或关闭后撤销其他设备。

没有短信或邮件恢复渠道。丢失验证器时，另一名管理员重新验证其密码后，同时重置该账户密码和两步验证；用户必须再次改密，操作进入审计。重要部署建议建立第二个受保护的管理员账户。若所有管理员均失去验证器，需要服务器操作者通过受控数据库恢复流程处理并保留审计，不能通过 AI 对话或重复启动环境变量绕过认证。

## 授权与隔离

所有练习、答题、撤销、统计、偏好、暂停词条、对话、训练、语音缓存及数据导出都从服务端认证上下文取 user_id。不能从客户端传入用户 ID 替代身份。资源读取与写入都校验所有者。教材词库是管理员管理的共享学习内容；每个人的学习状态独立。

聊天模型与语音模型均通过 users.group_id → group_models 授权。每次调用及语音缓存命中前都检查当前组、模型、服务商是否启用。管理员调用也受该规则约束。权限变化对新请求立即生效；已经发出的供应商请求可能仍完成。不接受客户端指定备用模型、供应商 URL 或 API Key。未授权模型不会请求供应商。没有 AI 调用次数、会话数量或业务额度字段。

## 供应商密钥与网络

APP_ENCRYPTION_KEY 为 base64 编码的 32 字节密钥，存放服务器环境。API Key 和 TOTP 用 AES-256-GCM 加密，AAD 绑定所属服务商/账户，管理读取不返回密钥。加密密钥不进入数据库或 Git。更换密钥前须设计解密重加密迁移；直接替换会让旧密文不可用。

兼容服务商只允许公开 HTTPS 基础 URL、443 端口，无 URL 凭据/查询参数。连接时解析并验证所有地址，拒绝内网、回环、链路本地、CGNAT 和基准测试地址；随后直接拨号验证过的 IP，不使用系统代理，不跟随重定向，保持 TLS 校验。供应商请求 120 秒截止，响应大小与 JSON 结构校验用于资源安全，与调用次数无关。供应商错误仅返回经过映射的消息，不回显其响应体或请求密钥。

语音缓存按用户隔离，带模型、音色、朗读指令与服务商配置版本，30 天过期；缓存前验证 MP3 类型与文件头。聊天和训练请求的幂等结果存数据库。外部供应商计费不能由本应用保证全局 exactly-once：进程在收到远程成功、写入本地前崩溃可能导致重试再次收费。

## 数据留存、导出与备份

个人导出包含自己的设置、复习、答题、对话和已提交训练，不含密码、会话、API Key、验证器密钥或他人记录。未交卷听力只导出摘要，避免提前泄露答案。导出是留存文件，当前没有一键恢复个人 JSON 的功能。

运维完整备份可在部署者自己的环境运行 `docker compose exec -T postgres pg_dump -U els -d els --format=custom > els-backup.dump`，并单独安全保存 APP_ENCRYPTION_KEY。先在隔离测试数据库使用 pg_restore 演练，再评估目标环境恢复。没有自动执行生产备份/恢复，没有销毁共享数据库。Compose 的 `down -v` 只出现在可丢弃 CI 栈。

数据库记录所有历史答题；撤销软标记并原子恢复状态。管理、密码和 MFA 操作记录操作者、动作、对象、时间，不记录密码或密钥。会话过期清理不等于全量隐私删除；完整账户删除、长期数据留存策略和正式上线安全评审仍需后续设计。
